# LANDED — プロジェクト概要

## 何のサイトか
トロントでワーキングホリデー(IEC)ビザ滞在中の日本人が、同じくワーホリで来る日本人向けに始める
「生活立ち上げサポート」個人ビジネスのランディングページ。単一HTMLファイル(`index.html`)。

現在 Netlify Drop で仮公開中: https://landed-workingholiday.netlify.app
(手動ドラッグ&ドロップでデプロイしているだけの状態。GitHub連携やビルドパイプラインはまだ無い)

## ブランド
- 名前: **LANDED**
- キャッチコピー: 「勝負は、初日。」
- コアの哲学: 「経験こそ、財産。」— 代行業者ではなく、本人が経験する部分(面接・生活)はそのままに、
  そこに迷わず辿り着くための段取り・情報提供だけを行う、というスタンス
- トーン: 落ち着いた・誠実・煽りすぎない。ターゲットはワーホリで来る日本人(20代前半〜後半が中心)

## デザインシステム
- カラー: インディゴ(#13213D)+ TTCレッド(#C8281B、トロント市電の色)+ 真鍮色(#A9824F)+ ペーパー(#EAEDF2)
- フォント: 見出し = Zilla Slab / Noto Serif JP、本文 = Inter / Noto Sans JP
- モチーフ: 空港の到着スタンプ、フライトパス、チケットの見た目(点線の区切り)
- 日本語/英語の切り替えあり(`data-lang`属性 + CSSでの出し分け、JSトグル)

## 法的に気をつけている/確認中の点
- 移民・ビザに関する法的助言はしない(RCIC/弁護士の領域と明確に線引き、フッターに免責文言あり)
- 求人斡旋・仕事探しサポートはオンタリオ州のEmployment Protection for Foreign Nationals Actにより
  外国人労働者への有料斡旋が規制されている可能性があるため、**無料オプション**として提供している
- 荷物預かりは無料だが、紛失・破損の免責を明記
- ビジネス登録・保険・税務・ビザ条件との整合性などは別途専門家に確認予定(Geminiにセカンドオピニオンを取得中)
